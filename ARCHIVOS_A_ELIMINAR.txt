## 🗑️ COMANDO PARA ELIMINAR TODO

Windows (PowerShell):
```powershell
Remove-Item package.json, package-lock.json -Force -ErrorAction SilentlyContinue
Remove-Item load-env.js, netlify-inject-env.js -Force -ErrorAction SilentlyContinue
Remove-Item netlify.toml -Force -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force node_modules, netlify -ErrorAction SilentlyContinue
```

Linux/Mac (Bash):
```bash
rm -f package.json package-lock.json load-env.js netlify-inject-env.js netlify.toml
rm -rf node_modules netlify
```
